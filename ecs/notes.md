
## NOTES (ECS)

     When you hit a similar decision (e.g., "should X be a component or a separate entity?"), run this checklist:

     ┌─────────────────────────────────────────────────────┬───────────────────────┬───────────────────────────────────────────┐
     │Question                                             │If yes, lean separate  │If yes, lean same-entity                   │ 
     ├─────────────────────────────────────────────────────┼───────────────────────┼───────────────────────────────────────────┤ 
     │Does X have a different lifetime than the entity?    │✓                      │                                           │
     ├─────────────────────────────────────────────────────┼───────────────────────┼───────────────────────────────────────────┤ 
     │Can there be multiple X's per entity?                │                       │✓                                          │
     ├─────────────────────────────────────────────────────┼───────────────────────┼───────────────────────────────────────────┤
     │Can there be X's with no entity at all?              │✓                      │                                           │
     ├─────────────────────────────────────────────────────┼───────────────────────┼───────────────────────────────────────────┤
     │Does X's data overlap with the entity's data?        │                       │✓ (they share the same position/transform) │
     ├─────────────────────────────────────────────────────┼───────────────────────┼───────────────────────────────────────────┤
     │Does X need independent control (input, animation)?  │✓                      │                                           │
     ├─────────────────────────────────────────────────────┼───────────────────────┼───────────────────────────────────────────┤
     │Does removing the entity break X's purpose?          │                       │✓                                          │
     ├─────────────────────────────────────────────────────┼───────────────────────┼───────────────────────────────────────────┤
     │Would N of these exist simultaneously?               │✓                      │                                           │
     └─────────────────────────────────────────────────────┴───────────────────────┴───────────────────────────────────────────┘
